# Чифс-бот — ИИ-помощник для постов канала о Kansas City Chiefs

Бот сам следит за новостями о Chiefs — статьи (Arrowhead Pride, Chiefs.com, Arrowhead Addict,
ProFootballTalk, CBS Sports, ESPN, Bing) и быстрые
репосты твитов инсайдеров (Reddit r/KansasCityChiefs и r/nfl, Bluesky @chiefs) —
пишет по ним посты на русском в стиле канала и присылает вам в личку черновики с кнопками.
Вы нажимаете «Опубликовать» — пост уходит в канал.

## Что умеет

- **Автоматически**: раз в час проверяет статьи, раз в 10 минут — репосты твитов (📰 / ⚡ в пометке) → отбрасывает неинтересное и дубли → присылает готовые посты (с картинкой из статьи или скриншотом твита).
- **/news** — проверить новости прямо сейчас.
- **/find тема** — найти свежее в интернете (Bing News) и написать пост.
- **/post тема** или просто текст — написать пост на вашу тему без поиска.
- **Кнопки под черновиком**: ✅ Опубликовать · ❌ Пропустить · ✂️ Короче · 🔄 Другой вариант.
- **Ответ на черновик** своим текстом («добавь статистику», «убери иронию», «сделай заголовок про Келси») — бот перепишет.
- **/style** — показать стиль. Сам стиль — в файле `style.md`, правьте свободно.

## Подготовка (5 минут)

1. **Создайте бота**: в Telegram напишите @BotFather → `/newbot` → получите `BOT_TOKEN`.
2. **Узнайте свой user id**: напишите @userinfobot → это `ADMIN_IDS`.
3. **Добавьте бота админом в канал** (права: публикация сообщений). `CHANNEL_ID` — это `@username` канала
   или числовой id вида `-100…` для приватного канала (перешлите пост из канала боту @userinfobot, он покажет id).
4. **Ключ API** от ai.starimg.ru → `API_KEY`. Адрес и модель уже прописаны в `.env.example`
   (`API_BASE_URL=https://ai.starimg.ru/v1`) — любой OpenAI-совместимый сервис подойдёт.
5. Скопируйте `.env.example` в `.env` и заполните.

## Настройки (.env)

| Переменная | Значение |
|---|---|
| `CHECK_INTERVAL_MIN` | как часто проверять новости (по умолчанию 60) |
| `MAX_POSTS_PER_RUN` | максимум черновиков за одну проверку (5) |
| `FAST_INTERVAL_MIN` | как часто проверять Reddit/Bluesky (10). Меньше 5 не ставьте — Reddit начнёт отдавать 429 |
| `FAST_MAX_PER_RUN` | максимум черновиков из твитов за раз (5) |
| `FEED_CACHE_SEC` | на сколько секунд кэшировать ленты, чтобы Reddit не отдавал 429 (240) |
| `RATE_LIMIT_COOLDOWN_SEC` | на сколько отложить ленту, упёршуюся в 429 (1800 = 30 мин) |
| `REDDIT_CLIENT_ID` / `REDDIT_CLIENT_SECRET` | ключи приложения Reddit, см. ниже |
| `ADD_SOURCE_LINK` | добавлять ссылку «Источник» в конец поста (1/0) |

Источники — в `config.py`: `FEEDS` (статьи), `REDDIT_SUBS`, `BLUESKY_ACCOUNTS`, `KEYWORDS`.
У каждой ленты третий параметр — фильтровать ли по ключевым словам до обращения к модели.
Для общих лент НФЛ (ESPN, CBS, PFT, Bing, r/nfl) он `True`: новости о других командах отбрасываются
бесплатно, не занимая лимит и не тратя токены. Для профильных лент о «Чифс» — `False`.
Из Reddit берутся только посты с пометкой источника в заголовке — `[Schefter] ...`, `[Chiefs] ...` — так там
помечают репосты твитов; обсуждения и мемы отсекаются.

### Ключи Reddit (нужны на сервере)

Публичный RSS Reddit почти всегда отвечает `429 Too Many Requests`, если запрос идёт с адреса хостинга.
Бесплатное приложение снимает это ограничение (100 запросов в минуту):

1. Откройте https://www.reddit.com/prefs/apps → **create another app**
2. Тип — **script**, redirect uri — `http://localhost`, название любое
3. `client_id` — короткая строка под названием приложения, `client_secret` — поле **secret**
4. Впишите их в `.env` как `REDDIT_CLIENT_ID` и `REDDIT_CLIENT_SECRET`, перезапустите бота

В логе при старте появится `Reddit: токен приложения получен`. Если ключей нет, бот работает через RSS —
на домашнем компьютере обычно нормально, на VPS большинство запросов будет теряться.

## Модели и расход

Бот работает в два этапа, чтобы не тратить дорогую модель на мусор:

1. **Фильтр** (`FILTER_MODEL`, по умолчанию `claude-haiku-4-5`) — получает заголовок и первые 1000 символов,
   отвечает «интересно / нет». ~600 токенов на новость. Через него проходит всё.
2. **Автор** (`MODEL`, по умолчанию `claude-sonnet-5`) — получает стиль канала и статью (до `ARTICLE_MAX_CHARS`
   символов), пишет пост. ~3000 токенов на пост. Вызывается только для отобранных новостей.

Ориентир по ценам Anthropic за 1 млн токенов (вход/выход): Haiku 4.5 — $1/$5, Sonnet 5 — $2/$10,
Opus 4.8 — $5/$25. Тарифы ai.starimg.ru смотрите у них, пропорции обычно те же.
Если качество текста Sonnet устраивает — оставляйте; хочется «дороже-лучше» — `MODEL=claude-opus-4-8`.

Расход по каждому запросу пишется в лог: `claude-sonnet-5: 2870 in / 412 out`.
Ещё уменьшить: реже проверять (`CHECK_INTERVAL_MIN`, `FAST_INTERVAL_MIN`), меньше `MAX_POSTS_PER_RUN`,
меньше `ARTICLE_MAX_CHARS`.
